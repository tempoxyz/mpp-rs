Added out-of-order session vouchers inside a reorder window. A server opts in with `SessionMethod::with_reorder_window` (`DEFAULT_REORDER_WINDOW` is 30 seconds, and windows are capped at `MAX_REORDER_WINDOW_SECS`, one day; clients treat a longer advertised window as none) and advertises `reorderWindow` in its session challenges. It then accepts each voucher increment `(after, cumulativeAmount]` once, also below the highest accepted voucher, as long as it is newer than the window, and refuses stale and replayed vouchers with `acceptedCumulative` and `requiredCumulative` problem members. Requests are still charged from the highest voucher. A client paying such a server allocates each voucher from the channel's counter (atomically in the channel store, with one `UPDATE ... RETURNING` for `SqliteChannelStore`) and sends it with `after`, so concurrent requests, and processes sharing a store, pay over one channel without waiting for each other. It moves its counter up to a server's accepted amount only when the session snapshot carries a voucher this channel's signer signed for it; bare amounts in receipts and refusals never raise it. With a reorder window, a voucher whose write loses a compare-and-swap on a store shared by several server instances is applied again to the fresh state, up to eight times. Without `reorderWindow` nothing changes. Session voucher payloads gained the optional `after` field, `TempoSessionMethodDetails` gained `reorder_window`, `ChannelState` gained `window`, `PaymentErrorDetails` gained `accepted_cumulative` and `required_cumulative`, `ErrorCode` gained `ConcurrentUpdate` (returned by `ChannelStoreAdapter` for a lost compare-and-swap, previously `Internal`), the client `ChannelStore` gained `allocate` and `allocates_atomically` (it raises the counter to an absolute target or by an amount, whichever is higher, in one atomic step; only stores that override both, such as the memory and SQLite stores, are allocated from concurrently; others pay serialized), and `PaymentProvider` gained `observe_refusal`.
