Added Persona KYC as an identity provider, as mppx's `mppx/extensions/identity/persona` does, behind the new `identity-persona` feature. `identity::ext::persona::Persona` starts inquiries (`start_inquiry`, returning a one-time link to Persona's hosted flow) and builds a `PaymentCheck` (`payment_check`) and a `Verifier` (`verifier`) that require an approved inquiry for a reference ID the server derives: every 402 advertises `Identity-Required: kyc;issuer="https://api.withpersona.com"`, no payer is `missing` (401) and no accepted inquiry `forbidden` (403), both with the onboarding URL in `Link: <url>; rel="kyc"`, and a Persona API failure is `unavailable` (503). Lookups recheck each inquiry's reference ID, status, template and `max_age`, follow up to three pages only on the Persona API origin, never follow redirects, and can cache approvals (only approvals) in a `Store` per Persona organization and template for `cache_ttl` (default 300 seconds). `verify_wallet` (EOA) and `verify_wallet_with` (custom check, such as for smart accounts) check that a signed message holds a server-issued nonce and the wallet's DID and return the DID; `did`, `did_in` and `normalize` build and normalize `did:pkh` reference IDs.
